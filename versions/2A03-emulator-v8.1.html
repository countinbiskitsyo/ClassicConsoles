Pick the machine above before loading — each Atari system runs on its own core, so a 2600 dump will not boot on the 7800 core. The 2600 and 7800 use a joystick with one or two buttons; the Lynx adds its two Option keys. The 5200's analogue stick and number pad are only partly expressible on a keyboard, so some 5200 games will want a real controller.

Version history

The NES tab emulates the 2A03 CPU, the 2C02 picture unit and all five audio channels, with mappers NROM, MMC1, UxROM, CNROM, MMC3, AxROM and GxROM. The SNES, N64 and PlayStation tabs run RetroArch cores through EmulatorJS, fetched from cdn.emulatorjs.org — those two tabs need an internet connection the first time each core is used.

Bring your own cartridge dumps; none are included, and ROMs you load stay in your browser. Control layouts download as files rather than being kept in the browser, so save the layout if you want it to survive a reload.
